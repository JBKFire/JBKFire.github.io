Input format

Each key is a numeric block ID. Its value is an array of [x,y,z] positions:

{ "4": [[0,0,0],[1,1,1]], "6": [[0,23,1],[1,4,1]] }

Coordinates are automatically split into 32×32×32 chunks. Empty positions become air (block ID 0).
The binary writer follows the chunk/RLE and Avro-style integer encoding used by the supplied reference editor.
